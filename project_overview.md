# TusiCurezza - AI-Powered Legal Document Assistant

## Project Overview
TusiCurezza is a React-based web application that provides an intelligent Chatbot for Italian legal documents with a focus on proper citations using a Supabase hybrid search (RAG + FTS) combined with Cohere embeddings + chat stream to generate answers with citations. 


## Core AI Components

### 1. Document Processing RAG pipeline (`create-document-index.ts`)
- **Purpose**: Processes and indexes Italian legal documents stored in XML format
- **Key Features**:  
  - Chunking that respects original document structure hierarhcy to create text chunks that correspond to document sections, enabling both semantic and doc section retrieval. 
  - Embedding using Cohere 
  - Vector storage in Supabase (a postgres db) 

### 2. Advanced Chat Implementation (`new-get-suggestions.ts`)
- **Purpose**: AI Chat streaming with citations 
- **Key Features**:
  - Hybrid Search (Vector similarity search + FTS) using Supabase
  - Real-time streaming responses from Cohere 
  - Cohere citations mapped to original document sections 
  - Follow up questions auto generated by ChatGPT 

## Technical Implementation

### Frontend Architecture
- **Core Components** (`src/components/dashboard/pdf-chat/`):
  - `pdf-chat-view.tsx`: Main chat interface with split-view layout
  - `pdf-view/pdf-view.tsx`: Advanced PDF viewer with search and navigation
  - `pdf-chat-thread-messages-context.tsx`: Message state management
  - `pdf-chat-threads-context.tsx`: Thread management and persistence

### State Management
- **Context-Based Architecture**:
  - Thread management
  - Real-time message synchronization
  - Efficient state updates for streaming responses
- **Data Persistence**:
  - Supabase integration for chat history
  - Thread-based conversation management

### User Experience
- **Interactive Features**:
  - Real-time message streaming
  - Clickable citation that scrolls pdf view to proper document sections
  - Dynamic text highlighting
  - One-click ai generated follow up question selection

## Technical Stack
- **Frontend**: React.js with Material-UI (using the Devias Kit Pro basic website template)
- **Backend**: Next.js API routes
- **AI/ML**: 
  - Cohere for embeddings and chat
  - OpenAI for suggestion generation
- **Database**: Supabase (postgres db) with vector storage
- **Document Processing**: XML parsing with custom metadata extraction

## Notable Technical Achievements
1. **Custom Document Processing**: Developed a specialized pipeline for processing structured legal documents while preserving their hierarchical organization
2. **Efficient Vector Search**: Implemented a sophisticated vector search system that combines semantic similarity with metadata filtering
3. **Real-time Interaction**: Built a streaming chat interface with citations and follow up questions
4. **Citations**: Cohere citations mapped to original document sections, allowing users to click on a citation and have the pdf view scroll to the proper section
5. **Multilingual Support**: Leveraged Cohere's multilingual models to handle Italian legal text effectively
6. **Contextual Understanding**: Created a system that maintains document context through metadata preservation and citation tracking
